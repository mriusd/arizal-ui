Introduction Exchange logic Contract API

API

Base URL http://127.0.0.1:8080/v1 (local). JSON request/response unless noted. Machine-readable schema: GET /v1/openapi.yaml. Paths below are relative to /v1. HTTP is rate-limited per client IP (default 300 requests / 60s; http_rate_limit_per_min in clearbook.toml, 0 = off). Over limit → 429 rate limited; retry in Ns + Retry-After. IP from first X-Forwarded-For, else X-Real-IP, else TCP peer. GET /health is not counted; WebSocket frames after upgrade are not counted.

WebSocket

WS /ws

Connect to ws://127.0.0.1:8080/v1/ws (or wss:// in production). Text frames are JSON. After connect the node fans out every broadcast to all sockets — subscribe only requests an immediate snapshot for that channel; filter by market / trader on the client.

Client → server

{
  "op": "subscribe",
  "channel": "book",
  "market": "btc-hit-80000-up-daily-…"
}

Only op: "subscribe" is handled. market is required for book, tape, trades, and resolved. Other frames are ignored.

Subscribe channels

Push-only channels (no subscribe)

market, last_yes, quote, account, ledger, ledger_delta, holders, orders, live tape / trades / book / config refreshes.

config

Sent on connect, on subscribe config, and about once a minute when gas_fee refreshes. Subset of GET /config (gas_fee, trading_fee_factor, chain_id, exchange only). 

{
  "channel": "config",
  "gas_fee": 50000,
  "trading_fee_factor": "70000000000000000",
  "chain_id": 31337,
  "exchange": "0x…"
}

markets

On subscribe and when a market locks or resolves. markets is the same array as GET /markets. 

{
  "channel": "markets",
  "markets": [ /* same objects as GET /markets */ ]
}

market

When a market opens (push only). market matches GET /markets/:id / one element of GET /markets. 

{
  "channel": "market",
  "op": "opened",
  "market": { /* Market */ }
}

resolved

On subscribe with market, and again when any peer for that strike/expiry resolves. markets are resolved Market rows (same shape as GET /markets) sharing kind + barrier (+ high) + expiry with the subscribed id (hit up and down both included; newest resolve first). 

{
  "channel": "resolved",
  "market": "btc-hit-80000-up-daily-…",
  "strike": "…",
  "expires_at": 1735689600,
  "markets": [ /* Market[] */ ]
}

price

On subscribe and on each spot tick (~1s). Same core fields as GET /price, plus spot (HTTP has price / ts / barrier / source only). 

{
  "channel": "price",
  "price": "97500.12",
  "spot": "97480.00",
  "barrier": "97000",
  "ts": 1735689000,
  "source": "binance"
}

book / quote

Subscribe book (with market) publishes both immediately. Further book/quote pushes after place/cancel/fill, rate-limited to about once per market per 80ms (cancel-all forces an immediate book). bids_yes / bids_no match GET /markets/:id/book (WS uses market instead of market_id, adds book_hash, omits status). 

{
  "channel": "book",
  "market": "btc-hit-80000-up-daily-…",
  "seq": 42,
  "bids_yes": [[450, "10.0"], [400, "5.0"]],
  "bids_no": [[500, "8.0"]],
  "book_hash": "0x…"
}
{
  "channel": "quote",
  "market": "btc-hit-80000-up-daily-…",
  "best_yes_bid": 450,
  "best_yes_ask": 550
}

best_yes_bid / best_yes_ask match those fields on GET /markets rows.

tape / tape_snapshot

Subscribe tape returns tape_snapshot (latest ~100 events for that market, plus recent chain confirms). Live events arrive as tape. Each event matches one element of GET /markets/:id/tape. 

{
  "channel": "tape_snapshot",
  "market": "btc-hit-80000-up-daily-…",
  "events": [ /* same as GET /markets/:id/tape items */ ]
}
{
  "channel": "tape",
  "seq": 10,
  "event": { "seq": 10, "ts": 1735689000, "kind": "Accepted", "order_id": 1, "market_id": "…" }
}

trades / trades_snapshot

Subscribe trades returns trades_snapshot (up to 200 fills for that market). Each fill matches GET /trades items. Live fills use channel: "trades" with a single fill. 

{
  "channel": "trades_snapshot",
  "market": "btc-hit-80000-up-daily-…",
  "fills": [ /* same as GET /trades?market=… */ ]
}
{
  "channel": "trades",
  "fill": {
    "fill_id": 12,
    "market_id": "btc-hit-80000-up-daily-…",
    "yes_price": 550,
    "size": "2.0",
    "taker_side": "Yes",
    "confirmed": false
  }
}

last_yes

After each fill (instead of republishing the full markets list). price is the fill’s Yes price (¢); same meaning as last_yes_price on GET /markets. 

{
  "channel": "last_yes",
  "market": "btc-hit-80000-up-daily-…",
  "price": 550
}

account

Push only. Filter by trader (lowercase). Always includes volume_30d and taker_coeff (same fields as GET /account). Variants:

Deposit / withdraw delta:

{
  "channel": "account",

  "op": "deposit",
  "amount": 100000000,
  "tx_hash": "0x…",
  "ts": 1735689000,
  "volume_30d": 2500000,
  "taker_coeff": 0.07
}

Absolute collateral after redeem / split / merge / fill / close (and fund refresh):

{
  "channel": "account",
  "trader": "0x…",
  "collateral": 95000000,
  "ts": 1735689000,
  "volume_30d": 2500000,
  "taker_coeff": 0.07

Hourly volume snapshot (optional collateral):

{
  "channel": "account",
  "trader": "0x…",
  "ts": 1735689600,
  "volume_30d": 2500000,
  "taker_coeff": 0.07,

ledger

Full snapshot after resolve / settle confirm / redeem / split / merge. positions matches GET /ledger/positions; trades matches GET /ledger/history. 

{
  "channel": "ledger",
  "trader": "0x…",
  "positions": [ /* GET /ledger/positions */ ],
  "trades": [ /* GET /ledger/history */ ]
}

ledger_delta

Match-time patch (merge into local state; do not replace full history). trades / positions items use the same shapes as GET /ledger/history and GET /ledger/positions. remove_positions drops those sides from the Positions tab. 

{
  "channel": "ledger_delta",
  "trader": "0x…",
  "trades": [ /* new history rows */ ],
  "positions": [ /* upserted position rows */ ],
  "remove_positions": [{ "market_id": "…", "side": "Yes" }]
}

holders

After positions change on a market. yes / no match GET /markets/:id/holders (WS uses market instead of market_id). 

{
  "channel": "holders",
  "market": "btc-hit-80000-up-daily-…",
  "yes": [{ "trader": "0x…", "shares": "10.0", "usdc_staked": 5000000 }],
  "no": []
}

orders

Open-order snapshot for one trader after cancel-all or market lock cancels. orders matches GET /ledger/orders. 

{
  "channel": "orders",
  "trader": "0x…",
  "orders": [ /* same as GET /ledger/orders */ ]
}
