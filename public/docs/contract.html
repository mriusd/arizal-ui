Contract

The address in clearbook.toml is a single non-upgradeable Exchange (no proxy). Constructor (usdc, aggregator, operator) sets the EIP-712 domain to Arizal / 1 and tradeAdmin / oracle to the operator. Balances and markets live on that address. Yes/No positions are ERC-1155 NFTs — one token id per market side (tokenId(marketId, side)). A contract change needs a new deploy (new address).

Exchange calls

CallWhoEffect
deposit / withdrawuserMove USDC in or out of that wallet’s balance.
split / mergeuserMint or burn a complete Yes+No set (ERC-1155).
redeemuserAfter resolution, $1 per winning share (losing dust is burned).
createMarkettrade adminOptional standalone open (tests / tooling). Usual path is lazy create inside settleFill via MarketSpec.
settleFilltrade adminTwo EIP-712 orders (signer = trader or off-chain ApproveAgent / AgentAuth), optional MarketSpec if the market is missing, mint shares, charge taker takerFee + signed gasFee (both credit tradeAdmin).
settleClosetrade adminMove share NFT from seller to buyer and pay the seller, minus the taker fee (credits tradeAdmin). No user signature.
settleoracleHit early on barrier touch, or any kind after expiry from the aggregator. Write-once.
safeTransferFrom / setApprovalForAlluserTransfer or approve position NFTs.
setTradeAdminoperatorOnly account that may create markets and settle fills/closes.
setOracle / disableOracleChangesoperatorName the oracle; optionally freeze further oracle changes forever.
setURIoperatorERC-1155 metadata URI template.

Orders are EIP-712 type Order(address trader,string marketId,string side,uint16 price,uint256 size,string orderType,string tif,uint256 nonce,uint256 salt,uint256 expiresAt,uint256 gasFee). Side is "Yes" / "No"; order type and TIF are human-readable strings so MetaMask shows a clear prompt. Session wallets use off-chain ApproveAgent (no on-chain authorizeSession / approveAgent). The domain name is Arizal, version 1, and the verifying contract is the exchange.
